# 🧪 Chemicals Inventory Management System

Aplikasi inventory chemicals dengan fitur tracking penggunaan, multi-user workspace, dan akses mobile.

## 🚀 Fitur Utama

- ✅ Login & Register dengan Workspace
- ✅ CRUD Chemical (Tambah, Lihat, Edit, Hapus)
- ✅ Tracking Penggunaan Chemical
- ✅ Auto Status Update (Active/Expired/Empty)
- ✅ Multi-user dalam 1 Workspace
- ✅ Responsive Design (Mobile & PC)
- ✅ Real-time Sync Data
- ✅ Search & Filter
- ✅ Riwayat Penggunaan

## 📱 Akses

- **Web:** https://chemicals-inventory.vercel.app
- **Mobile:** Sama dengan web (responsive)
